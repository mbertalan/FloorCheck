# Floor Check — release notes to paste on ficsit.app

Paste the block below into the **Changelog** field when uploading the version
(ficsit.app: Edit mod → Versions → the version → Changelog). It is the same wording as `CHANGELOG.md`,
trimmed to what a player needs. Keep the two in step: change one, change the other in the same commit.

---

## 1.1.3

**The research card now says what you get and what it costs.**

- On the HUB milestone screen, **Rewards** shows a *Floor Check* card with its icon and a line describing the
  height readout, and **Cost** lists **10 Iron Rod** and **10 Iron Plate** with their item icons.
- Both panels were blank in every build up to 1.1.2, so there was no way to see the price before buying it.
- The price itself has not changed: the same 10 Iron Rod + 10 Iron Plate and 30 seconds it always was. Only the
  card you read was empty.
- Nothing else changed. If you already bought the research, you keep it.
